# 2–3-комнатные новостройки Красноярска — карта под IT-ипотеку

Интерактивная карта подбора квартир: **74 лота в 33 ЖК** (данные на 11.10.2026).
Открывается на телефоне и на компьютере, работает без сборки — это одна HTML-страница.

## Что умеет

- метки-ценники по каждому ЖК: минимальная цена, тип комнатности и число лотов;
- карточка ЖК со всеми лотами: площадь, этаж, цена, ₽/м², срок сдачи, отделка, платёж, ссылка на объявление;
- калькулятор: меняете первый взнос, ставку и срок — платежи пересчитываются сразу;
- фильтры: комнатность (2 / 3), районы, диапазон цены, площадь от, «без сданных домов», «только с отделкой», сортировка;
- слои «Схема» (OpenStreetMap) и «Спутник» (Esri);
- на телефоне — нижняя панель со списком и кнопки «Карта» / «Список».

## Как смотреть

- Онлайн: GitHub Pages (ссылка в разделе About репозитория).
- Скачать Excel с теми же лотами: `krasnoyarsk-2-3k-novostroyki.xlsx`.

## Как обновить данные

1. Отредактируйте `lots3.py` (3-комнатные) или блок `LOTS` в скрипте сборки 2-комнатных.
2. Пересоберите страницу: `python build_site.py` (в родительской папке проекта).
3. Закоммитьте изменения — GitHub Pages обновится автоматически через минуту.

## Важно

Цены, площади и наличие — по данным агрегаторов (ДомостройРФ, Сибдом, N1, Arevera, Яндекс
Недвижимость) на 11.10.2026. Лоты уходят быстро, условия и цены обязательно проверяйте у застройщика.
Координаты — OpenStreetMap (Photon); близкие ЖК слегка разведены, чтобы подписи не накладывались.
Это не реклама и не оферта — личная подборка.
